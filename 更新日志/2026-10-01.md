# 2026-10-01 更新

> 本日主线：**把桌面做成"像 Windows/macOS 的样子"**，并修掉三个用户实测发现的问题。

## 一、你能看到的变化

### 1. 桌面重做：启动后是干净桌面 + 桌面图标
- **不再默认打开任何窗口**（原来一开机就是"文件 + 终端"两个窗口平铺）
- 桌面**左侧竖排三个图标**：**文件管理 / 终端 / 系统设置**（Windows 的桌面图标就是左侧竖列）
  - 48px 彩色底座 + 名称标签；悬停有浅底 + 青色描边
  - **点一下即打开**（与 Dock 一致的单击）
- 桌面图标与 Dock **共用同一套矢量图形**（抽成 `draw_app_icon`）—— 两处各画一套必然走形

### 2. 标题栏：macOS 红绿灯 → **Windows 三键**
- 右上角三个按钮：**最小化 `—` / 最大化 `□` / 关闭 `✕`**，各 46px × 标题栏高
- 符号全部 **1px 细线**（Windows 就是细线）
- 悬停：**关闭键变 Windows 的红底白叉**（#C42B1C），另两个浅灰底
- **命中区就是按钮本身**（原来的红绿灯圆点只有 10px，必须外扩才好点、还容易误触）
- **三个键全部真实生效**：
  - `—` 最小化 → 窗口收进 Dock，**点 Dock 图标原位置恢复**
  - `□` 最大化 / 还原
  - `✕` 关闭

### 3. 主题：默认白色，**用户可切换**
- 默认仍是**明亮（纯白）**，新增入口可切深色：
  - **设置中心 →「外观」页**（设置窗口默认就打开这一页）
  - **控制中心**（点顶栏右侧的状态簇）第一行
- 切换**立即生效**（壁纸/顶栏/窗口全变），并写入 `/var/lib/aether/settings.json`，重启记得

### 4. 安装向导现在**能关掉**
- 右上角新增**关闭按钮**（与窗口三键同款）；`Esc` 原本也能关，但界面上没有可见入口
- **安装进行中该按钮禁用**（写到一半取消是危险操作，不该给）

## 二、修掉的问题

| 问题 | 根因 | 修法 |
|---|---|---|
| **点一下"文件"图标弹出一大堆窗口** | 点击链用 `press = mouse_down \|\| click_pending`，其中 `mouse_down` 是**电平信号**——按住期间每帧为真，于是每帧开一个新窗口（直到 8 个上限）。Dock 之所以没暴露：点已开的应用是"聚焦"（幂等），桌面图标是"打开"（非幂等） | 桌面图标与控制中心改用**一次性信号 `click_pending`** |
| **鼠标在虚拟机里灵敏度太高** | `main.rs` 对相对位移**硬编码 ×2**（早期在 QEMU 里嫌 PS/2 计数偏小加的补偿，被当成了全局常量） | 默认改回 **1:1**；倍数交给用户设置（设置中心 →「输入」→ 鼠标速度：慢/标准/快），越界值夹取 25–300 |
| **系统颜色发粉** | 浅色令牌是粉调 | 浅色基色全部改**中性白**（壁纸实测 `(254,254,254)`，R−G=0） |
