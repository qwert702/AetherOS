# 更新日志

本目录记录 AetherOS 的**每次改动**（按日期一个文件），给"我改了什么"一个固定的落点，
不必再翻 git log 或几十个提交信息。

## 约定

- **一天一个文件**：`YYYY-MM-DD.md`
- 每份包含：**改了什么 / 为什么 / 怎么验证 / 已知问题**
- 面向"使用者视角"写：先说**你能看到的变化**，再说实现细节
- 只写**已提交并推送**的改动（未落地的想法不写进来）
