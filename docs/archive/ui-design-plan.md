# AetherOS UI 设计系统 · 详细执行计划

日期：2026-09-19
状态：待执行（用户已确认方向）
范围：全套设计系统，直接落地到 Rust 代码（`aether-compositor`），不做 HTML 原型

---

## 1. 设计方向：苹果级克制的「以太」

一句话：**保留深空 + 极光的品牌基因，用苹果级的克制执行。**

苹果的高级感来自四件事：极少的颜色、极准的字距、大量留白、精确的层级。本次设计系统以此为准绳：

| 原则 | 具体含义 |
|---|---|
| 克制用色 | 极光渐变只出现在 3 处：壁纸、AI 元素、品牌标识。其余全部中性灰阶 |
| 精确层级 | 三级 surface 拉开明度差，半透明 + 发丝描边模拟玻璃感（软件光栅做不到真模糊） |
| 排版优先 | 字阶严格、行高宽松、小字号下限 11px，中文必须清晰 |
| 动效少而准 | 只有布局切换、弹窗、Toast 三处动效，时长 150–400ms |

**保留**：macOS 式骨架（顶栏 / Dock / 窗口结构）、红绿灯按钮语义（重绘得更小更精致，悬停才显示符号）。
**废除**：安装器品红配色（并入主色板）、散落的魔数常量、与 macOS 雷同的视觉细节。

## 3. 设计令牌（Design Tokens）定案

落地位置：`draw.rs` 的 `palette` 模块扩为 `theme` 模块，作为全系统单一事实来源。

### 3.1 色板

**中性层级**（深空基调，明度阶梯拉开）：

| Token | 值 (RGB) | 用途 |
|---|---|---|
| `bg_top` | 16, 18, 26 | 壁纸渐变顶 |
| `bg_bottom` | 32, 36, 50 | 壁纸渐变底 |
| `surface_1` | 38, 40, 48 | 窗口/面板主面 |
| `surface_2` | 46, 48, 57 | 卡片、侧栏选中 |
| `surface_3` | 56, 58, 68 | 悬停态、输入框 |
| `inset` | 28, 29, 36 | 凹陷区（终端底色等） |
| `hairline` | 255,255,255 @ 8% | 发丝描边（玻璃感关键） |
| `text` | 240, 241, 246 | 主文字 |
| `text_dim` | 158, 160, 172 | 次要文字 |
| `text_faint` | 108, 110, 122 | 占位/禁用文字 |

**强调色**（克制使用）：

| Token | 值 (RGB) | 用途 |
|---|---|---|
| `accent` | 64, 190, 205 | 主青：选中、焦点、主按钮 |
| `accent_violet` | 150, 130, 220 | 辅紫：AI 相关元素 |
| `success` | 52, 199, 123 | 完成、在线 |
| `warning` | 255, 179, 64 | 预警、L2 确认 |
| `danger` | 255, 92, 88 | 危险操作、L3、错误 |
| `info` | 90, 160, 250 | 信息提示 |

**AI 专属**：`ai_gradient`（青 → 紫双色插值），仅用于 AI 指令条焦点环、AI 头像、思考中动效。

**窗口控制**（红绿灯精致化）：close 255,95,86 / min 254,188,46 / zoom 39,201,63，直径 12px，间距 8px，悬停显示符号。

### 3.2 字阶

| 级别 | 字号 | 字重 | 用途 |
|---|---|---|---|
| `title` | 20 | Bold | 弹窗标题、面板大标题 |
| `body` | 14 | Regular | 正文、菜单项 |
| `caption` | 12 | Regular | 辅助说明、状态栏 |
| `label` | 11 | Medium | 按钮文字、标签（**下限，不得更小**） |
| `mono` | 13 | Mono | 终端、代码 |

行高 = 字号 × 1.5。中文渲染目标：11px 清晰可读（Step 2 验证）。

### 3.3 圆角 / 间距 / 阴影

- 圆角 3 档：`r_sm = 8`（按钮、输入框）、`r_md = 12`（卡片、弹窗）、`r_lg = 16`（窗口）
- 间距：4 的倍数网格，常用 4/8/12/16/24/32；窗口间距沿用 `GAP = 14`
- 阴影 3 档：`elev_1`（窗口浮起，强度 0.25）、`elev_2`（弹窗，0.4）、`elev_3`（模态，0.55）

### 3.4 动效

| 场景 | 时长 | 缓动 |
|---|---|---|
| 悬停反馈 | 150ms | ease-out |
| 布局切换 / 窗口吸附 | 250ms | ease-in-out（沿用现有动画系统） |
| 弹窗进出 | 200ms | ease-out + 轻微缩放（0.96→1.0） |
| Toast | 250ms 入 / 400ms 出 | ease-out |

## 4. 执行步骤（5 步，每步独立提交、独立验证）

### Step 1 · 设计令牌收口
**文件**：`draw.rs`（palette → theme 模块）、`layout.rs`、`main.rs`、`text.rs`
- 按 §3 建 theme 模块；全局搜索替换散落常量（MENUBAR_H、TITLE_H、DOCK_ICON 等纳入 theme）
- 消灭魔数，不改任何视觉输出（纯重构）
- **验证**：`cargo test -p aether-compositor` 通过 + `--shot 1` 截图与改前像素级一致

### Step 2 · 字体与文字渲染质量
**文件**：`text.rs`
- 排查 fontdue 光栅化参数：字号取整、基线对齐（刚修过基线 bug，注意不回归）、亚像素定位策略
- 若参数调优不够，评估替换 CJK 字体（需 hinting 良好、license 允许打包）
- **验证**：`--shot` 截图中 11px 中文清晰可读；现有 4 张布局截图文字不劣化

### Step 3 · 核心组件重绘
**文件**：`draw.rs`（menubar/dock/窗口/按钮/Toast 绘制函数）
- 窗口标题栏：红绿灯 12px 精致化 + 悬停符号、标题栏高度与字阶对齐
- 顶栏：半透明层级 + 发丝描边、AI 状态指示重绘
- Dock：玻璃底座 + 图标重绘（统一圆角矩形 + 渐变基调，去 macOS 雷同感）
- 按钮/输入框：四状态（默认/悬停/按下/禁用）全部落 token
- 壁纸：极光渐变升级（更柔和的色带过渡，漂移速度放缓）
- **验证**：`--shot 1-4` 截图，逐张与改前对比，用户审阅

### Step 4 · AI 界面补全（差异化重点）
**文件**：`draw.rs`、`main.rs`（apply_action / AI 面板路径）、`aetherd` 协议侧如需新增消息类型
- AI 指令条：焦点态加青紫渐变环，思考中加呼吸动效
- 回复气泡：区分用户/AI/工具调用三类样式；工具调用卡片显示工具名 + 参数摘要（"AI 干了什么"可见，呼应审计设计）
- **L2+ 权限确认弹窗**（新建）：
  - 标题：操作名称 + 风险等级徽章（L2 黄 / L3 红）
  - 正文：工具名、参数明文（如目标盘 `/dev/vda`）、后果说明
  - L3 额外要求：输入目标名回显确认（配合 tools.rs 的 confirm 参数）
  - 按钮：「允许一次」/「拒绝」（danger 色描边），无"永久允许"（安全决策，不做）
  - IPC：aetherd `NEEDS_CONFIRMATION` → 弹窗 → 用户选择 → 带 approval 重发（roadmap M4 欠账）
- AI 状态指示：本地模型/云端/离线三态，青/紫/灰区分
- **验证**：端到端——`aetherd serve` + 合成器，触发一次 L3 工具，弹窗出现、拒绝/允许路径都通

### Step 5 · 安装器统一 + 全局走查 + 截图归档
**文件**：`draw.rs`（installer 绘制段）、`docs/`
- 安装器品红 → 主色板（危险操作仅按钮保留 danger 红）
- 全界面走查：圆角/间距/字阶一致性，对照 §3 token 表逐项核对
- `--shot 1-4` + 安装向导截图，更新 `docs/screenshot-*.png`
- 更新 `INDEX.md`、`roadmap.md`（文档落后实际进度三个里程碑，顺带修正）
- **验证**：截图归档 + 全 workspace 测试通过

## 5. 边界（本次不做的）

- 不改布局引擎（layout.rs 逻辑）、IPC 协议语义、交互逻辑——纯视觉层 + L2+ 弹窗这唯一的功能补全
- 不做启动器/通知中心/设置的完整功能（那是 M2 的开发任务）；本计划只做视觉体系，M2 开发时直接消费
- 不引入"永久允许"权限选项、不做亮色系主题（发布后再说）

## 6. 风险与对策

| 风险 | 对策 |
|---|---|
| 每帧 CPU 重绘，新增视觉效果拖慢帧率 | 新效果先 `--shot` 静态验证，再交互模式掐帧；阴影/渐变缓存能复用就复用 |
| 字体问题可能无法纯参数解决 | Step 2 预留换字体方案；换字体涉及 license 审查，单独确认 |
| L2+ 弹窗需要 IPC 协议扩展 | 尽量复用现有 `Response::Action` 通道；必须扩展时在 `aether-ipc` 加消息类型，保持向后兼容 |
| 视觉改动回归布局 | 每步跑 `cargo test -p aether-compositor`（布局测试 3 项）+ 四布局截图对比 |

## 7. 验收标准（整体）

1. `cargo test --workspace` 全绿（含 Step 4 新增测试）
2. `--shot 1-4` 截图达到"苹果级克制"观感：中性为主、极光点睛、文字清晰
3. L3 工具端到端：弹窗 → 回显确认 → 执行/拒绝，双路径走通
4. 安装器与桌面视觉统一
5. `docs/` 截图与文档更新到最新状态
