## 0. 口径与三态定义

**当前事实**：本项目结论建立在 **x86_64 + Buildroot + fbdev 软件光栅** 一条路径上；
现有证据全部来自 VMware / VirtualBox / QEMU（TCG）虚拟机，**没有任何物理机验收记录**。

| 状态 | 含义 |

| **不适用** | 架构上本版本就不提供该能力（有意不做 / 无后端），不是待办缺陷 |

### 0.1 后端实现方式（AetherOS 侧）

- **显示**：DRM→fbdev→用户态帧缓冲，**软件光栅化**（fontdue 字体 + 自研布局/绘制）；未接 Mesa/DRM KMS/GPU 加速，未接 Wayland 生产合成路径。
- **输入**：Linux evdev（`/dev/input/event*`），同时解析 `EV_REL`（相对位移）与 `EV_ABS`（绝对坐标，含量程读取）。
- **音频**：不链接 libasound；走 alsa-utils 子进程 `aplay -l` / `aplay -q -` / `amixer get|set Master`；提示音运行时合成 WAV。
- **网络**：busybox `udhcpc` 拉 DHCP；网络页只读 `/proc/net/route`、`/proc/net/fib_trie`、`/etc/resolv.conf`；DNS 可经 aetherd 鉴权写入。**静态 IP 有意不做**。
- **存储**：安装器建 ext4 持久化分区（卷标 AETHER）挂 `/var`；可移动存储检测 + **只读**挂载 + 卸载。
- **外设探测**：蓝牙读 `/sys/class/bluetooth` 适配器名/地址；打印读 `/run/cups/cups.sock` 与 `/etc/cups/printers.conf` 队列名；均为**只读检测**。
- **电源**：L3 工具经 aetherd 鉴权审计 → aether-init（PID 1）停服务 → `sync()` → `reboot(RB_POWER_OFF)`；注销定义为重启合成器。

## 10. 统计与待办

- **验证过（仅 VM）**：见上表备注"仅虚拟机"各行；证据均在 `docs/证据/`，环境为 VMware / VirtualBox / QEMU。
- **未验证（含全部物理机项）**：真机显卡、真机网卡/无线、真机声卡、真机外设、真机磁盘与电源动作、UEFI 引导 —— 需按 H1 清单在至少两台物理机上补证据。
- **不适用**：架构上无后端或有意不做的能力（GPU 加速、Wi-Fi、蓝牙配对、打印作业、休眠唤醒、电池、静态 IP、多显示器/旋转等）；这些行不得在后续版本里被口头改成"支持"。
- **VM 专有 / 架构不适用说明**：VMware SVGA、vmxnet3、VirtualBox VBoxVGA、QEMU virtio 等均为**虚拟机虚拟设备**，对应专有驱动只存在于虚拟机环境；物理机上不存在这些设备，相关行不迁移为真机兼容结论。
