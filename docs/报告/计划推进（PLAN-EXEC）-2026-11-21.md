1. **PATH 决定门禁真假**：本机 git 在 `D:\Git\cmd\git.exe`、bash 在 `C:\Tools\w64devkit\w64devkit\bin\bash.exe`，不在系统默认 PATH 的进程里会报 `FileNotFoundError / 找不到 bash`，门禁看起来是红的，实际是环境缺项。
