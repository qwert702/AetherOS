# AetherOS AI 权限模型 v0

原则：AI 无所不知（可读），但不会不问就动手（受控可写）。

## 权限等级

| 等级 | 名称 | 示例 | 策略 |
|---|---|---|---|
| L0 | 只读 | 查状态、读文件、列目录 | 直接执行，记审计日志；**路径受白名单约束**（见机制 3） |
| L1 | 可逆写 | 改壁纸、开/关服务、移动窗口 | 直接执行，记日志，可一键撤销 |
| L2 | 敏感写 | 装卸软件、改系统设置、删除用户文件 | 弹确认卡片，用户点头才执行 |
| L3 | 危险 | 格式化、改内核参数、批量删除、网络开放端口 | 双重确认 + 输入确认短语 |

## 机制

1. **能力标签**：每个工具调用声明所需等级；aetherd 内置等级表，工具无法自我提权。
   `install_disk`（整盘擦除）为 L3：除等级闸门外，还要求 `confirm` 参数回显目标盘设备名。

2. **审计日志**：所有 AI 操作落盘 `/var/log/aether/aether-audit.log`（追加写，含等级、工具、参数、裁决）。
   审计写入失败不阻断执行，但错误会显式返回调用方并落 stderr，不允许静默零留痕。

   裁决列取值：

   | 值 | 含义 |
   |---|---|
   | `allowed` | 闸门放行（L0/L1，或 L2+ 已带有效令牌） |
   | `needs_confirmation` | L2+ 未获确认，已下发确认请求 |
   | `denied_by_user` | 用户在确认卡片上点了"拒绝"，令牌被撤销 |
   | `denied` | 该操作此前被用户拒绝过，冷却期内直接拒绝（不再重复询问） |
   | `failed` | 闸门放行但工具执行失败（含路径白名单拒绝），与"真的执行成功"区分开 |

3. **只读也有边界**：`read_file`（L0）只能读**用户数据区**与 aether 自身的配置/日志。
   - 允许根（Linux）：`/home`、`/etc/aether`、`/var/log/aether`、`/run/aether`、`/tmp`
   - 拒绝：`/etc` 其余部分、`/proc`、`/sys`、`/dev`、`/boot`、`/root` 及任何白名单外的路径
   - 路径先 `canonicalize` 再校验，因此 `..` 穿越与符号链接都绕不过去
   - 白名单根之内的凭证类子路径（`.ssh`、`.gnupg`、`.aws`、`.kube`、`.netrc`、`id_rsa` 等）仍然拒绝

   实现理由：aetherd 以 PID 1（root）运行，没有路径约束的"只读"等于"可读 /etc/shadow、/proc/self/environ"。

4. **确认令牌绑定确认方**：L2+ 操作会签发一次性令牌（128 位、5 分钟、用后即废、绑定 tool+参数），
   但令牌本身**不等于放行权**——只有**已注册的 UI 通道**能兑现它。

   - 客户端连接后先发 `Request::RegisterUi { key }`；密钥来自 `AETHER_UI_KEY` 环境变量，
     或 aetherd 首次启动时生成并写入 `/var/log/aether/ui.key`（Unix 下 0600）
   - 未注册连接：既不会收到确认令牌（L2+ 请求被直接 403），也不能兑现令牌（403）
   - 因此"任何能连上 7311 的进程都能自助放行"不再成立

   诚实边界：这挡不住**能读到密钥文件**的本机进程。IPC 尚无用户级认证（M4 规划），
   所以它是"提高门槛 + 让确认方成为服务端可断言的事实"，不是完整的多方授权。

5. **拒绝是服务端的事实**：用户在确认卡片上点"拒绝"时，合成器会发送
   `Request::ConfirmCancel { token }`。服务端据此撤销令牌、落 `denied_by_user` 审计，
   并把该 (tool, 参数) 记入 300 秒拒绝冷却——冷却期内同一操作**直接 `denied`**，
   不再反复弹卡片。此前"拒绝"只存在于合成器的本地 UI 状态里，服务端既不撤销令牌也无留痕。

6. **读到的文件内容不上云**：混合推理路由**不再用"消息条数"判断复杂度**
   （每轮工具调用会给消息表 +2 条，旧规则导致"任何多轮工具任务在第 3 轮必然上云"）。
   现在 `read_file` 被标记为敏感输出：其结果一旦进入上下文，本轮推理强制走本地通道。

7. **撤销栈**（规划中，未实现）：L1 操作自动生成逆操作；AI 面板提供"撤销上一步"

8. **熔断**（规划中，未实现）：单位时间 L2+ 调用超阈值自动挂起会话，防止提示词注入导致的连环操作

9. **注入防线**（规划中）：外部内容（网页、文件）进入 AI 上下文时打标记，其中的指令不视为用户指令
