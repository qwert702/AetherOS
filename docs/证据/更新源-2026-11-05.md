## 二、部署边界

- 这是 **探测包**，不是真实应用更新；版本号与当前一致，guest 不会把它当成新版本应用；
- nginx 对 `*.json` 有全局 deny，已加入精确放行：

```nginx
location = /updates/update.json { try_files $uri =404; }
```
