# VMware 首次试用记录（2026-11-21）

> 目的：在真实虚拟化平台（VMware Workstation 17）上做一次**非 QEMU** 的启动与运行验证，
> 补 H2 硬件矩阵里“VMware SVGA / PCnet32”这一格的实测数据，同时作为 H1 真机验收的预演。
> 本文只记录串口与 VMware 日志能证明的事实；画面观感由 owner 现场确认，不代写“看起来正常”。

## 一、环境与配置

| 项 | 值 |
|---|---|
| 宿主 | Windows，VMware Workstation 17.0.0（Hyper-V 开启，VM 以 ULM 模式运行） |
| 虚拟机 | `E:\Aether\VM\vmware2\AetherOS-0.1.1.vmx`（2 GB / 2 vCPU / 4 GB 精简 SATA 盘 / NAT e1000? 实际 pcnet32） |
| 固件 | BIOS，`bios.bootOrder = "cdrom"` |
| 介质 | `aetheros.iso`（v0.1.1，27,262,976 B，sha256 `53580ae5…`） |
| 串口 | 输出到 `serial.txt`（115200n8） |
| 磁盘状态 | 空白 4 GB vmdk，未格式化 —— 因此 `aether-init` 按内存态运行 |

## 二、启动结果（串口原文）

- 内核：`Linux version 6.6.22`，命令行 `console=tty0 console=ttyS0,115200n8`
- 显卡：`vmwgfx 0000:00:0f.0: [drm] Running on SVGA version 2`，能力表含 `rect copy / cursor / multimon / gmr2 / command buffers`；
  `vmwgfx 0000:00:0f.0: [drm] fb0: vmwgfxdrmfb frame buffer device`
- 合成器：`aether-compositor: fbdev 1280x800 @32bpp stride=5120 字节序=Bgrx 通道 R(16,8) G(8,8) B(0,8) ioctl(get var=0,fix=0 put=0) 通路=write`
- 服务序列：`["network", "aetherd", "ops", "compositor", "getty"]`；
  `aetherd IPC 服务已启动 127.0.0.1:7311`，`UI 通道密钥 /run/aether/ui.key (0600)`
- 网卡：`pcnet32: eth0: registered as PCnet/PCI II 79C970A`（VMX 写的是 e1000，VMware 实际按 guestOS=other 给了 pcnet32 —— 内核正好带 `CONFIG_PCNET32`）
- 输入：`VMware Virtual USB Mouse` 被 `hid-generic` 接管，串口可见 REL 事件累积（鼠标移动被 compositor 收到）
- 健康：`aether-ops: 巡检#93 up=1382s mem=683/1976MB 服务=aetherd=✓ compositor=✓ getty=✓ network=✓ ops=✓`
- 帧数：串口末尾 `已渲染 40200 帧`（uptime ≈ 1400 s，约 **28–29 fps**，ULM 软件虚拟化下的近似值）

## 三、结论

- **VMware SVGA（vmwgfx）路径通过**：DRM 驱动加载、fbdev 模拟出 `/dev/fb0`、合成器以 1280x800/32bpp 正常上屏并持续出帧。
- **PCnet32 网卡路径通过**：驱动注册、network 服务健康。
- **输入路径通过**：USB 鼠标事件进入合成器（`[input] REL` 累积计数可见）。
- **未执行 / 未验证**：
  1. 安装器未在 VMware 里跑（空白盘保持未格式化）；
  2. 视觉与交互观感由 owner 现场确认，本文不替代截图/录屏证据；
  3. 帧率是串口计数推算，非 `bench-gate` 口径；如需正式数字要在 guest 内跑 `damage-bench` / `bench-gate`；
  4. ULM 模式（Hyper-V 共存）性能低于原生，不能代表物理机性能。

## 四、复跑方式

1. VMware 打开 `E:\Aether\VM\vmware2\AetherOS-0.1.1.vmx`，开机（BIOS 从光驱引导）；
2. 串口证据：`E:\Aether\VM\vmware2\serial.txt`；
3. 要试安装器：让安装器写那块 4 GB vmdk（只影响该虚拟盘）；
4. 关闭：guest 内正常关机，或 VMware 挂起。
