## 二、首次失败与修复

首次 run #1 在 Linux 6.6.22 的 objtool 阶段失败：

```text
fatal error: libelf.h: No such file or directory
fatal error: gelf.h: No such file or directory
```

修复：workflow 的 Ubuntu 依赖加入 `libelf-dev`、`libdw-dev`，重新触发 run #2。

## 三、边界

- 这是 **demo 认证模式** 产物（镜像内 root 无口令），只用于构建验证，**不能直接发布**。
- 未做 QEMU/物理机启动验证；不能仅凭 `offset 510=55aa` 宣称“可装机”。
- `site/release.json` 仍指向旧的 v0.1.1 发布资产，尚未上传新 ISO。
- `release-readiness.py --iso <候选>` 对旧 release.json 结果为 **7/9**：isohybrid 通过，
  但大小（27,262,976 vs 42,991,616）和 SHA256 不一致。这是预期的：候选不等于已发布。
