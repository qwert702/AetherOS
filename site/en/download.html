Troubleshooting

It boots to buildroot login: instead of the desktop

The ISO was not attached or booted (often an unconnected virtual optical drive, or the VM booted from its disk).

Wrong resolution or garbled screen

The compositor follows the real framebuffer mode and logs the probe result to the serial port. Standard VGA/SVGA adapters work; 1280×800 looks best.

I want the kernel and compositor logs

Redirect the serial port to a file (VirtualBox: serial port → host pipe/file; VMware: serial0.fileName).

Mouse too fast or too slow

Settings → Input → mouse speed (slow / standard / fast). Default is 1:1 and applies immediately.
