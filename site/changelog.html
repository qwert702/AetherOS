# 2026-10-02 更新

一、三页一览

页数据来源是否新增 IPC
应用内建应用清单（5 个）+ 真实打开路径否
网络/sys/class/net/*、/proc/net/route、/proc/net/fib_trie、/etc/resolv.conf否
权限与隐私aetherd 权限门写的 /var/log/aether/aether-audit.log否

为什么三页都不走 IPC：合成器是 root，并且本来就直接读系统文件（/var/apps 已装应用、

时区）。这三页要的都是只读展示，内核与 aetherd 已经把这些真值写在文件里。

新增 Request 变体要同步 aetherd/src/server.rs 的鉴权分支与 request_variants_are_gated 清单，

那是为需要跨进程授权的新能力准备的 —— 只读展示不该动它。

二、「权限与隐私」页细节

  • 显示：审计日志路径、总条数 / 被拒绝 / 失败 / 无法解析的行数、最近 8 条记录

（等级 · 工具 · 结论，附"多久以前"）。

  • 三条如实原则：

1. 没记录就说"暂无审计记录"（Live 会话还没发生工具调用时是常态），不显示空表；

2. 坏行被计数并显示（无法解析 N），不静默丢弃 —— 审计页最不该做的事就是假装没有记录；

3. 时间只说"多久以前"，不编造日历时间（Unix 秒转本地日期要一套历法换算，与这页目的无关）。

  • 解析是纯函数（parse_line / parse_log），新增 6 项单测，含：坏行必须被计数、

结论分类（用户拒绝 vs 无 UI 拒绝 vs 失败）、时间戳在未来不 panic。

三、顺带修掉的两处过期断言

三页全部接入后，已经没有"不可用页"了，两处测试还在 PAGES.iter().position(|p| !p.enabled).unwrap()

（settings.rs 与 draw.rs）→ 直接 panic。已改成有条件断言：有不可用页才验，没有就跳过，

规则本身仍由 apply_hit 保证（将来再加占位页会自动重新生效）。

四、验证

  • 工作区 368 项测试全绿；Windows / musl 双目标 0 警告
  • 走查图 16/16 一致；规模门禁 3/3（24,360 行 / 45 文件）

五、待办（顺延）

  • Alt+Tab 跳过/恢复已最小化的窗口（现在会切到不可见的窗口）
  • 设置页的走查图覆盖：三页目前只有单测与渲染断言，没有视觉基线

（需要给走查工具加 --settings-page N 演示态）

  • 需要"改"而不只是"看"的能力（改网络配置、改权限策略）才需要新 IPC

# 2026-10-01 更新

一、你能看到的变化

1. 桌面重做：启动后是干净桌面 + 桌面图标

  • 不再默认打开任何窗口（原来一开机就是"文件 + 终端"两个窗口平铺）
  • 桌面左侧竖排三个图标：文件管理 / 终端 / 系统设置（Windows 的桌面图标就是左侧竖列）

- 48px 彩色底座 + 名称标签；悬停有浅底 + 青色描边

- 点一下即打开（与 Dock 一致的单击）

  • 桌面图标与 Dock 共用同一套矢量图形（抽成 draw_app_icon）—— 两处各画一套必然走形

2. 标题栏：macOS 红绿灯 → Windows 三键

  • 右上角三个按钮：最小化 — / 最大化 □ / 关闭 ✕，各 46px × 标题栏高
  • 符号全部 1px 细线（Windows 就是细线）
  • 悬停：关闭键变 Windows 的红底白叉（#C42B1C），另两个浅灰底
  • 命中区就是按钮本身（原来的红绿灯圆点只有 10px，必须外扩才好点、还容易误触）
  • 三个键全部真实生效：

- — 最小化 → 窗口收进 Dock，点 Dock 图标原位置恢复

- □ 最大化 / 还原

- ✕ 关闭

3. 主题：默认白色，用户可切换

  • 默认仍是明亮（纯白），新增入口可切深色：

- 设置中心 →「外观」页（设置窗口默认就打开这一页）

- 控制中心（点顶栏右侧的状态簇）第一行

  • 切换立即生效（壁纸/顶栏/窗口全变），并写入 /var/lib/aether/settings.json，重启记得

4. 安装向导现在能关掉

  • 右上角新增关闭按钮（与窗口三键同款）；Esc 原本也能关，但界面上没有可见入口
  • 安装进行中该按钮禁用（写到一半取消是危险操作，不该给）

二、修掉的问题

问题根因修法
点一下"文件"图标弹出一大堆窗口点击链用 `press = mouse_down \\click_pending，其中 mouse_down` 是电平信号——按住期间每帧为真，于是每帧开一个新窗口（直到 8 个上限）。Dock 之所以没暴露：点已开的应用是"聚焦"（幂等），桌面图标是"打开"（非幂等）桌面图标与控制中心改用一次性信号 click_pending
鼠标在虚拟机里灵敏度太高main.rs 对相对位移硬编码 ×2（早期在 QEMU 里嫌 PS/2 计数偏小加的补偿，被当成了全局常量）默认改回 1:1；倍数交给用户设置（设置中心 →「输入」→ 鼠标速度：慢/标准/快），越界值夹取 25–300
系统颜色发粉浅色令牌是粉调浅色基色全部改中性白（壁纸实测 (254,254,254)，R−G=0）

# 版本发布说明

>

v0.1.0 — 2026-09-29

首个公开版本。 可引导 ISO，QEMU / VirtualBox / VMware 三个平台实测开机；可安装到虚拟磁盘后独立引导。

First public release. Bootable ISO verified on QEMU, VirtualBox and VMware; installable to a virtual disk and bootable from it.

系统内核之上，全部自研 / A userspace written from scratch

  • PID 1（aether-init）：服务编排、持久化分区、串口日志、故障自愈。
  • 窗口合成器（aether-compositor）：直接写 framebuffer 的立即模式合成器，

自带窗口管理、平铺布局、阴影与圆角、字形缓存、脏行上屏与自适应帧率。

  • 终端模拟器：PTY + VT 解析器，自己实现，不是包一层现成的终端库。
  • 中文输入法：拼音输入 + 候选框。
  • AI 中枢（aetherd + aether-ipc）：NDJSON over TCP 的线协议，

每一次工具调用都要过权限闸门，L2+ 操作弹确认框；架构上客户端 → 用户自己的网关 → 各家模型，

系统内不存放上游 API Key。

能装市面上的 Linux 软件 / Runs real Linux software

  • 静态二进制与常见动态依赖都能装能跑；镜像补齐 ncurses + terminfo、zlib、openssl、libffi、expat。
  • 实测：从宿主拉下应用包 → aetherd 安装 → 在桌面里跑起 htop 3.3.0（Ubuntu 24.04 官方包）。
  • 应用包格式与安装器（aether-install）自研。

工程与验证 / Engineering

  • 规模、测试数、走查图都进门禁：scripts/repo-stats.py --check（文档口径）、

cargo test --workspace、musl 静态目标 --all-targets 零警告、

scripts/archive-ui-shots.py --check（界面截图逐像素比对）。

  • 可引导 ISO 约 38.5 MB。
  • 许可证：GPL-3.0-only。
