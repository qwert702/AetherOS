QEMU：一条命令

最省事的路径。装好 QEMU 后直接跑（把文件名换成你下载的那个）：

qemu-system-x86_64 -m 1024 -cdrom aetheros-0.1-amd64.iso -boot d

想装到虚拟磁盘（装完可脱离 ISO 独立引导）：

qemu-img create -f qcow2 aether.qcow2 4G
qemu-system-x86_64 -m 1024 -hda aether.qcow2 -cdrom aetheros-0.1-amd64.iso -boot d
⚠️ v0.1.0 的 ISO 装机不可用。 实测该 ISO 未经 isohybrid 处理（首 512 字节无 MBR 签名）， 不能 dd 到磁盘引导；安装器检测到这一点会拒绝执行且不写入目标盘。 引导与跑 Live 桌面不受影响。构建侧已补上 isohybrid 步骤（platform/build-iso.sh）， 需重新构建 ISO 后才支持装机。
进桌面后点 Dock 上的安装向导，把系统装到虚拟磁盘；重启时把 -boot d 去掉即从磁盘引导。

VirtualBox

1

新建虚拟机

类型选 Other Linux (64-bit)，内存 1024 MB 以上，先不建硬盘（Live 体验）。

2

挂载 ISO

设置 → 存储 → 光驱 → 选择下载的 aetheros-0.1-amd64.iso。

3

启动

开机即进桌面。想在磁盘上持久化，就在虚拟机里加一块虚拟硬盘后再用安装向导。

如果卡在 buildroot login: 而不是桌面，多半是 ISO 没挂上或虚拟光驱未连接 —— 检查上一步的挂载。

VMware

1

新建虚拟机

「稍后安装操作系统」→ 客户机类型 其他 Linux 5.x 内核 64 位，内存 1024 MB 以上。

2

挂载 ISO 并启动

虚拟机设置 → CD/DVD → 使用 ISO 映像文件 → 选择下载的 ISO，勾选「启动时连接」。

3

强制从光盘启动

若虚拟机里已有别的系统，BIOS 会优先从硬盘启动 —— 在 .vmx 里加一行 bios.bootOrder = "cdrom"，或开机时按 F2 调整启动顺序。

系统要求

最低

64 位 x86 虚拟化 · 1 GB 内存 · 支持 1024×768 的显示适配器 · 一个光驱（或虚拟光驱）

建议

2 GB 内存 · 1280×800 显示 · 网络（NAT 即可，用于装软件与 AI 网关）

已在 QEMU / VirtualBox / VMware 三个平台实测开机； 真实硬件上通常可用，但本项目当前以虚拟机为主要验证环境。

装不上？先看这几条

开机进了 buildroot login: 而不是桌面

说明 ISO 没被正确挂载/引导（常见于虚拟光驱未连接，或虚拟机从硬盘启动了）。检查 ISO 挂载，并强制从光盘启动。

屏幕分辨率不对 / 花屏

合成器按 framebuffer 实际模式绘制，并把探测结果写进串口日志。把虚拟机显示适配器设为标准 VGA/SVGA 通常即可； 分辨率以 1280×800 效果最好。

想看到内核与合成器日志

把串口重定向到文件即可（VirtualBox：串口 → 端口模式「主机管道/文件」；VMware：serial0.fileName）。 日志里能看到字体加载、framebuffer 模式与每帧渲染计数。

鼠标太灵敏 / 太慢

设置中心 →「输入」→ 鼠标速度（慢 / 标准 / 快），默认是 1:1，改完立即生效并持久化。
