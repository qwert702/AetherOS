30 秒看懂：它真的能跑真实软件

这段是真机录屏（QEMU 逐帧抓取，未剪辑）：在终端敲一行命令，从宿主拉下应用包， aetherd 装好 htop，再敲 htop —— 它就在自研的桌面里跑起来了。

为什么它和别的「自研系统」不一样

不重写内核 —— Android、ChromeOS 都用 Linux 内核，重写它没有差异化价值。力气全放在内核之上。

内核之上，一行都不是现成的

从 PID 1 到窗口合成器、终端模拟器（自写 PTY + VT 解析器）、中文输入法、AI 中枢，全部自研。 合成器直接写 framebuffer，带平铺布局、阴影与圆角、脏行上屏与自适应帧率。

能装市面上的 Linux 软件

静态二进制与常见动态依赖都能装能跑；镜像补齐 ncurses + terminfo、zlib、openssl、libffi、expat。 应用包格式与安装器同样自研。

AI 中枢带逐工具权限闸门

每一次工具调用都要过闸门，L2+ 操作弹确认框并记审计。架构是客户端 → 你自己的网关 → 各家模型， 系统里不存放上游 API Key。

三分钟跑起来

只需要一个虚拟机。完整步骤（含 VirtualBox / VMware 与校验和）在下载页。

1

下载 ISO

到下载页取 ISO（38.5 MB）与 SHA256 校验和。

2

QEMU：一条命令

qemu-system-x86_64 -m 1024 -cdrom aetheros-0.1-amd64.iso -boot d

VirtualBox / VMware 的图形化步骤见下载页。

3

想装到硬盘就点「安装」

Live 桌面里点 Dock 的安装向导，装完后可脱离 ISO 独立引导。

常见问题

为什么用 Linux 内核，而不是自己写一个内核？

因为重写内核没有差异化价值。Android、ChromeOS 都用 Linux 内核，真正决定体验的是内核之上那一层 —— 而那一层在这个项目里是全部自研的。完整理由见常见问题页。

能当日常系统用吗？

目前是 v0.1.0 早期版本，适合体验、开发与试验，不建议承载重要数据。 它能装真实软件、能装到磁盘持久化，欢迎试用并反馈问题。

怎么装软件？

用自研的应用包与 aetherd：wget -O- <包地址> | sh。 静态二进制与常见动态依赖都可以；打包说明见仓库的 docs/APP-PACKAGES.md。

AI 中枢会把我的数据发到哪里？

架构上系统不存上游 API Key：客户端连的是你自己的网关，再由网关转各家模型。 每一次工具调用都要过权限闸门，L2+ 操作弹确认框并写审计日志。

怎么反馈问题或参与？

到 GitHub Issues 提问题；能复现的 bug 请带上虚拟机平台、 版本号与串口日志。想参与开发可以直接提 PR。
